# OkayKaba - Clean lilac interface

Updated design proposal following the user's request for a clean UI without copying mascots or illustrations.

## Direction

- Keep the selected lilac/purple family with predominantly off-white surfaces.
- Remove mascots, character illustrations, avatars/photos, decorative drawings and scenery.
- Use only functional line icons, a profile initial and simple mood-face symbols.
- Compact pastel Activities cards inspired by the user's layout references, using OkayKaba's actual activities.
- Clear geometric typography, light borders, modest radii, limited shadows and black primary controls.
- A restrained stacked-paper treatment for daily inspiration; no copied therapist identity, popularity claims, orange theme or source branding.
- Only the active navigation item shows its label.

## Boards

1. Home, Daily Inspiration, Talk it through.
2. Calendar, Journal, To-do, Your space.

Daily quotes remain the default; optional Bible verses are OFF by default. The chat UI, notification controls and sharing settings remain proposals, not connected functionality. AI support must be identified clearly, and journal sharing must require explicit selection/consent before any external transmission.

Generated labels and sample calendar data illustrate composition, not the final domain model. Implementation must retain correct calendar arithmetic, one consistent mood vocabulary, accurate saving/error states and accessibility.

The boards were created with the built-in image-generation tool. Exact prompts are saved alongside them. No app code, backend, live theme or Git state was changed by this design-only revision.
