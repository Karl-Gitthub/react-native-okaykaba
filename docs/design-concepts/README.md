# OkayKaba design archive

This archive preserves the design concepts, screenshots, prompts, navigation notes and audits created alongside the application. It includes historical alternatives and revisions; inclusion does not mean every proposal was approved or implemented.

## Current design handoff

The approved mockups cover first-run, Today, Journal, Mood Calendar and Insights, activities, and Account. Start with the [ordered screen gallery](final-design-handoff/screen-gallery.md) or the [design handoff and navigation notes](final-design-handoff/review.md). For a single visual walkthrough, open [the HTML gallery](final-design-handoff/gallery.html) in a local checkout.

The dark theme and account-choice flow are approved for design. The designs include proposed authentication states. The application README tracks implementation and verification separately.

## Reading the archive

Later revisions supersede the portions of earlier boards that their notes identify. Preserve the earlier boards as design history. Audit recommendations describe intended behavior and verification gaps; they are not evidence of working authentication, cloud saving, accessibility compliance or tested animation.

Some historical prompt records and asset manifests contain workstation paths to generation inputs or original outputs. Those paths are provenance, not portable runtime dependencies. Review images are included beside their documents with relative links.
